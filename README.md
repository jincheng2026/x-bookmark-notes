# X 收藏备注

X 上收藏的东西，很容易就再也没打开过。收藏那一下你明明想好了「这个以后做教程用」「这个工具周末试试」，过两周再看，完全想不起来当时为什么存。

这个 Chrome 插件做四件事：

1. **收藏那一秒，写一句为什么。** 在 X 网页上点收藏，右下角弹一个小框，写一句「为什么存、打算怎么用」，回车保存。不想写就不管，8 秒后自己收起。
2. **收藏全文自动存成文件。** 每条收藏连同你那句话，存成一个 Markdown 文件，放在「下载」文件夹里的 `X收藏`。长推文、引用的推文、X 长文都存全文，短链换回原链接。手机上收藏的，下次电脑上打开 X 时自动补进来。第一次只导入最近 7 天或 30 天的收藏，更早的不碰。
3. **自动分类，有一个收藏页。** 用你电脑上的 Codex 或 Claude Code 给每条收藏自动分类：以后什么情况下翻它、能不能做成视频（教程、观点、科普）、多久内要做。插件里的收藏页按分类看、按到期先后排，能直接改分类、写备注。用的是你自己 Codex 或 Claude Code 账号的额度，不用填任何密钥。
4. **你的 AI 直接读。** 附带一个 Skill，教 Claude Code、Codex 怎么查你的收藏、按分类整理、拿一条收藏开工。你问「我收藏过哪些讲提示词的」，它先看你当时写的那句话，再看原文。

## 最省事：让 AI 帮你装

把下面这段话复制，发给你的 Codex 或 Claude Code：

```
帮我装 Chrome 插件「X 收藏备注」：https://github.com/jincheng2026/x-bookmark-notes 。先读这个仓库的 README，从 Releases 下载最新版的压缩包，解压到我的「文稿」文件夹里（那里已经有旧版的话，先问我）。然后一步一步告诉我怎么在 Chrome 里加载它：打开 chrome://extensions、打开右上角的「开发者模式」、点「加载已解压的扩展程序」、选哪个文件夹（给我完整路径）。这几步要我自己在 Chrome 里点，你提醒我就好。我装好以后插件会自动打开设置页，后面我跟着它走。
```

## 自己装（3 分钟）

1. 到 [Releases](https://github.com/jincheng2026/x-bookmark-notes/releases/latest) 下载最新版的 `x-bookmark-notes-版本号.zip`，解压，把解压出来的文件夹放到以后不会删的地方，比如「文稿」（Chrome 每次启动都从这里读插件，删了插件就没了）。也可以点仓库首页绿色的「Code」按钮，选「Download ZIP」。
2. Chrome 地址栏打开 `chrome://extensions`，打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选解压出来的 `extension` 文件夹。
4. 装好会自动打开设置页，跟着走三步：登录 X（已经登录就自动打勾）；选「导入最近 7 天」或「导入最近 30 天」，插件把这段时间里的收藏抓下来，存进「下载/X收藏」（更早的收藏不导入：一次翻太多页、访问太频繁，对账号不安全；以后新收藏的会自动加进来）；导入完自动打开收藏页。
5. 收藏页最上面有一张卡片「最后一步：装好 AI 自动分类」：点「复制给 AI」，发给你的 Claude Code 或 Codex。它会装好两样东西：一个本机小程序，让插件能调你电脑上的 Codex 或 Claude Code 自动分类；一个 Skill，让它以后能读你的收藏。装好以后卡片自己变成「装好了」，开始分类。

Edge、Arc、Brave 这些 Chrome 内核的浏览器同样能装。

## 平时怎么用

- **收藏**：点收藏（或按 b 键），右下角弹框，写一句，回车。Shift 加回车换行，Esc 收起（写了的字留作草稿）。
- **补写**：已收藏的推文旁边有个小标记，写过的显示「已记」，没写的显示「备注」，点它就能写或改。插件图标上的蓝色数字是今天收藏了还没写的条数，点开有清单，点「去写」直接跳过去。
- **马上做**：备注框底下点「用 Claude」或「用 Codex」，直接开一个新对话，开场白带着你的备注和推文原文；用别的 AI 就点「复制」。
- **收藏页**：左栏按分类看，「可做成视频」按多久内要做排好；卡片上能标准不准（标不准要写一句错在哪，AI 几秒后按你这句重分）、改分类、改状态、延期、不做了。
- **DIY 收藏页**：收藏页左栏有个「DIY」按钮，点一下复制一段话，发给你的 Codex 或 Claude Code。它会先一轮一轮问你想改哪里、改成什么样，复述一遍等你同意，再去改插件代码，改完提醒你刷新。改了什么记在插件文件夹旁边的「我的改动.md」，插件出新版时把它和新版一起发给 AI，照着再改一遍。
- **问 AI**：「我收藏过哪些讲 Claude Code 的」「整理一下我的 X 收藏」「这周收藏了什么，哪些能做成内容」。

## 文件长什么样

```
下载/X收藏/
  _索引.md                 所有收藏一行一条，最新的在上面
  _备注备份.json           备注的备份，重装插件时用来导回
  收藏/2026-10/2026-10-07_作者账号_推文编号.md
```

每个文件三段：「我为什么收藏」（你写的原话）、「原文」、「AI 整理」（AI 整理时加在最后）。想放进 Obsidian，在库里建一个指向 `X收藏` 的软链接。

## 数据去哪了

- 收藏和备注只在你自己的电脑上：插件存储一份，「下载/X收藏」一份。没有服务器，没有账号。
- 插件用你这个浏览器里已经登录的 X 网页去取收藏（调的是 X 网页自己用的书签接口），读不到也不保存你的密码。
- AI 分类时，收藏内容和你的备注交给你电脑上的 Codex 或 Claude Code，由它们按你自己的账号去调模型。
- 唯一的第三方：遇到 X 长文时，插件把那条推文的编号发给 `api.fxtwitter.com` 取全文。不想要就在弹窗底部取消勾选「抓 X 长文全文」。

## 碰到问题

- **图标上一个红色「!」**：点开看。最常见的是 Chrome 开了「下载前询问每个文件的保存位置」，插件没法自动存文件；到 Chrome 设置 → 下载内容关掉它，再点「再试一次」。
- **同步报「书签接口可能改了」**：X 改版了。打开一次 x.com/i/bookmarks，插件会从 X 网页自己的请求里学到新地址，再点同步。
- **别在扩展程序页点「移除」**：会清掉插件里的备注和草稿。要更新插件，在 `chrome://extensions` 点它卡片上的刷新图标。真要重装，装好后在弹窗点「导入备注备份」，选 `X收藏/_备注备份.json`。
- **手机上**：X App 装不了插件，照常收藏，回到电脑点插件图标，在「还没写为什么收藏」里补。

## 给开发者

```
extension/              插件本体（直接加载这个文件夹）
  background.js         认出收藏、存备注、抓收藏、写文件
  content.js            X 页面上的一层：弹框、小标记、替后台调书签接口
  card.html / card.js   备注框（插件自己的页面，X 网页碰不到里面的字）
  popup.*               插件弹窗
  setup.*               装好后自动打开的设置页：登录 X、导入、打开收藏页
  install-prompt.js     「复制给 AI」那段话（装本机小程序和 Skill），各个页面共用
  help.*                「怎么让 AI 用这些收藏」说明页
  shoucang.*            收藏页（从作者自用的收藏页搬过来）
  lib/classify.js       分类树、给 AI 的分类说明、结果校验
  host/                 本机小程序：xbn-host.mjs 调 Codex 或 Claude Code，install.mjs 安装
  lib/parse.js          整理 X 书签接口返回的数据
  lib/markdown.js       写 Markdown 文件和索引
  skill/x-bookmark-notes/   给 AI 的 Skill
test/e2e.mjs            无头 Chrome 装上插件、对着模拟的 x.com 走一遍，分类用假的 Codex（60 项）
```

```bash
node test/e2e.mjs
```

备注框、认出收藏、草稿这些交互，最早是作者给自己的内容工作流做的，自己用了一段时间以后，拆成了这个谁都能装的版本。
