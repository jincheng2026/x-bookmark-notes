怎么让 AI 用你的 X 收藏

插件把每条收藏存成一个 Markdown 文件。教 AI 一次，以后你问它就行。

一、收藏存在哪

「下载」文件夹里的 X收藏。每条收藏一个文件，放在 收藏/年-月/ 里；最外面的 _索引.md 是总表。

二、装好 AI 分类，教你的 AI 读收藏（做一次）

点下面的按钮，把复制好的一段话发给你的 Claude Code 或 Codex。它会做两件事：装一个本机小程序，让插件能用你电脑上的 Codex 或 Claude Code 自动给收藏分类（用你自己账号的额度，不用填任何密钥）；再装一个读收藏的 Skill，读几条收藏给你看，证明它读得到。

三、收藏页

    
点插件图标里的「打开收藏页」：左栏按分类看，「可做成视频」按多久内要做排好，卡片上能直接改分类、标准不准、写备注、点「马上做」。AI 分类装好以后，新收藏几秒到一两分钟内自动分好。

    
想按自己的用法改分类和这个页面，点左栏的「DIY」：复制一段话发给你的 Codex 或 Claude Code，它会先问你是做什么的、收藏来干什么，看看你最近的收藏，给你一套合你用的分类建议，你同意了再改。

  


  

    
四、以后这样问

    
    
      
  • 「我收藏过哪些讲 Claude Code 提示词的？」
    • 
      
  • 「整理一下我的 X 收藏」（AI 按分类表给每条分类，写在文件最末尾）
    • 
      
  • 「这周收藏了什么？哪些能做成内容，哪些快过时了？」
    • 
      
  • 在 X 上收藏时，备注框底下点「马上做」：直接开一个 Claude 或 Codex 新对话，开场白带着你的备注和原文。用别的 AI 就点「复制」。
    • 
    

    
分类表是默认的，想改就跟 AI 说「X 收藏的分类改成……」。

  


  

    
五、想放进 Obsidian 或别的笔记库

    
插件只能写进「下载」文件夹。在笔记库里建一个指向它的快捷方式就行，Mac 上跟 AI 说：「在我的 Obsidian 库里建一个指向 ~/Downloads/X收藏 的软链接」。

  


  

    
六、数据去哪了

    
    
      
  • 收藏和备注只存在你自己的电脑上：插件存储里一份，「下载/X收藏」里一份。
    • 
      
  • 插件用你这个 Chrome 里已经登录的 X 网页去取收藏，读不到也不保存你的密码。
    • 
      
  • AI 分类时，收藏的内容和你的备注交给你电脑上的 Codex 或 Claude Code，由它们按你自己的账号去调模型。
    • 
      
  • 遇到 X 长文时，插件会把那条推文的编号发给 api.fxtwitter.com 取全文。不想要就在插件弹窗里取消勾选「抓 X 长文全文」。
    • 
      
  • 别在 Chrome 扩展程序页点「移除」：会清掉插件里的备注。真要重装，装好后先在弹窗里「导入备注备份」，选 X收藏/_备注备份.json。
