# X 收藏

用户在 X 上收藏推文时，Chrome 插件「X 收藏备注」会弹一个小框，让他写一句为什么收藏；收藏的全文和这句话一起存成 Markdown 文件。这个 Skill 教你怎么用这些文件。

## 先找到收藏文件夹

默认在「下载」文件夹里的 `X收藏`：

- Mac、Linux：`~/Downloads/X收藏`
- Windows：`%USERPROFILE%\Downloads\X收藏`

不在那里，就找 `_索引.md`：

```bash
find ~ -maxdepth 5 -name "_索引.md" -path "*X收藏*" 2>/dev/null
```

还找不到，问用户一句收藏文件夹在哪，或者请他先装插件（插件说明里有「怎么让 AI 用这些收藏」）。

## 文件夹里有什么

- `_索引.md`：所有收藏一行一条，按收藏时间从新到旧：收藏时间、作者、我为什么收藏、讲什么、文件链接。先看它。
- `收藏/年-月/日期_作者账号_推文编号.md`：每条收藏一个文件。文件开头的属性有链接、作者、发布和收藏时间、「备注: 有 / 没写」、「状态: 收藏中 / 已取消收藏」。正文三段：
  - `## 我为什么收藏`：**用户本人收藏时写的原话**。
  - `## 原文`：推文全文，短链已换回原链接；有引用的推文、X 长文、图片视频也在这里。
  - `## AI 整理`（可能没有）：AI 之前补的分类，在文件最末尾。
- `_备注备份.json`：插件的备注备份，不用管，别改。

## 三条底线

1. **「我为什么收藏」只读，原样引用。** 那是用户本人的判断，你不改写、不总结掉、不往里面写字。你的看法和它不一致时，把不一致说出来。
2. **你只能写文件末尾的 `## AI 整理` 一段。** 文件其他部分插件会整份重写；用户改了备注，插件重写文件，这一段会没掉，那条就算「还没整理」，下次按新备注重做。
3. **不删文件、不挪文件、不改文件名。** 插件靠文件名认文件。

## 做法一：查收藏

用户问「我收藏过讲 XX 的吗」「之前存的那个 XX 工具叫什么」：

1. 先在 `_索引.md` 里找；找不到再全文搜：`rg -i -l "关键词" 收藏/`，同义词、中英文都搜一遍（比如「提示词」和「prompt」）。
   没有 `rg` 就用 `grep -ril "关键词" 收藏/`。
2. 读命中的文件，回答时分开说：**你当时写的**（引用「我为什么收藏」）和**原文说的**，附上推文链接和文件路径。
3. 有备注的收藏排在前面：用户当时就想好了怎么用，最可能是他要找的那条。

## 做法二：整理收藏（分类）

插件装了本机小程序以后会自动分类，分好的文件末尾已经有「AI 整理」，写着「插件自动分类」。用户说「整理一下我的收藏」「把新收藏分个类」时：

1. 先看还没分类的有多少。条数多，多半是插件的本机小程序没装好或者还没来得及分：先告诉用户，在插件的收藏页点左栏「开始分类」最快；用户要你来分，再接着往下做。
2. 找出还没整理的：`rg -L "^## AI 整理" -g "*.md" 收藏/`，一次最多整理 30 条，多了先问要不要继续。
3. 分类表在这个 Skill 的 `references/categories.md`，用户改过就按他改的。
4. 每条先读「我为什么收藏」，**按他的意图分**：他写了「可以做教程」，就按能做教程来分、来写怎么用；没写备注，才由你按原文判断，并写明是你猜的。
5. 在文件最末尾追加（文件末尾已有空行就直接接上），格式和插件自动分类的一样：

```markdown
## AI 整理

- 分类：AI 实操 / 工具；AI 实操 / AI 使用方法
- 讲什么：一句中文，英文帖也写中文
- 可做成视频：教程
- 多久内做：1 周内做
- 还读出：按用户的备注写这条能怎么用；没写备注就写「没写备注，以下是 AI 猜的：……」
- 整理于：2026-10-07 15:30（AI 手动整理）
```

「可做成视频」从教程、观点、科普里选，都不适合写「不适合」；「多久内做」只给能做成视频的写，档位见分类表，其他写「不适用」。

6. 整理完告诉用户：整理了几条、各分类几条、有几条没写备注是你猜的、有没有你拿不准的。

## 做法三：拿一条收藏开工

用户贴了插件「马上做」生成的开场白，或者说「拿这条收藏做个视频 / 写篇文章」：

1. 先读这条的「我为什么收藏」。没写就先问他为什么收藏，别自己猜方向。
2. 用两三句话复述：你理解他想拿它做成什么、给谁看、要用原文的哪部分。**等他确认再动手。**
3. 原文里的说法、数字要用进内容，先核对（打开链接、搜原始出处），推文里的话不一定对。
4. 动手时引用他的备注原话，不换成你的说法。

## 做法四：回顾最近收藏

用户问「这周收藏了什么」「收藏里哪些能做成内容」「有没有快过期的」：

1. 从 `_索引.md` 取时间范围内的收藏。
2. 按分类归堆；每堆先列写了备注的，引用他的原话。
3. 「多久内做」快到或已经过了的单独列出来，写清是哪天收藏的、按哪一档算的。
4. 没写备注的单列一行条数，提醒他：在插件图标里点「去写」可以补。
