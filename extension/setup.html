欢迎用 X 收藏备注

三步设置好。以后在 X 上点收藏，右下角会弹一个小框，写一句为什么存，回车就好。

1

登录 X

插件借你这个 Chrome 里登录的 X 去取收藏，读不到也不保存你的密码。

登录好了回到这里，会自动往下走

已经登录 X

2

导入以前的收藏

只导入最近一段时间的。一次翻太多页、访问太频繁，对账号不安全；以后新收藏的会自动加进来。

正在导入…

会在后台开一个 X 页面，抓完自动关掉。这一页可以关，插件会接着抓。

导入好了

每条收藏存成一个 Markdown 文件，在「下载」文件夹的 X收藏 里。

3

打开收藏页

按分类看收藏、标准不准、写备注、马上做，都在收藏页。第一次打开时，它会带你装好 AI 自动分类。

以前装过这个插件？，把以前写的备注找回来（选「下载/X收藏/_备注备份.json」），再导入收藏。
